## 二、JD 逐条“翻译成人话”

### 1️⃣ 「PB 级数据 + 数百万用户」

 **真实含义：**

  * 你不是在玩 Kaggle

  * 你必须考虑：

    * 数据分布漂移

    * 线上/离线一致性

    * 推理成本（latency & $$$）

    * 回滚、A/B、监控

👉 **面试重点会问：**

  * 你如何把一个模型 **从 notebook 变成 production**

  * 你如何评估模型在真实用户下的效果

* * *

### 2️⃣ 「Agent / 多模态 LLM / 后训练 / RL / 量化」

 **这段是 Shopify 的野心区，不是“全都会”要求**

他们真正关心的是：

技术| 他们想确认什么  
---|---  
LLM 后训练| 你是否理解 **SFT / RLHF / preference data**  
Agent| 你是否理解 **tool calling、planner-executor**  
多模态| 你是否理解 **embedding 对齐、跨模态搜索**  
量化| 你是否关心 **成本 & latency，而非只追求效果**  

👉 **重要信号** ：  
他们更喜欢 **“我用过 2 个，但用得很深”** ，而不是“我都听说过”。

* * *

### 3️⃣ 「与跨职能团队协作」

 **这是 Shopify 的硬文化要求**

你要习惯和：

  * PM 讨论“模型效果 ≠ 产品成功”

  * Backend 讨论 SLA / 扩展性

  * Data / Analytics 讨论指标定义

👉 **面试一定会问：**

  * “你如何向非 ML 人解释模型决策？”

  * “当模型效果好，但产品指标没提升时你怎么办？”

* * *

### 4️⃣ 「在线结对编程（自带 IDE）」

这点非常重要 ⚠️

 **意味着：**

  * 不是 LeetCode 刷题

  * 更像：

    * Python 数据处理

    * 简化版 ML pipeline

    * Debug / 重构一段不优雅的代码

👉 **你要准备：**

  * 用 **Python 快速写清晰、可维护的代码**

  * 会边写边解释你的思路
